# CompliPrint Print Agent: downloads

Installers for the **CompliPrint Print Agent**, the small program that lets
[CompliPrint](https://compliprint.patriotpf.com) print labels straight to a
store's label printers, with no print dialog.

This repository holds the signed installers only. The source code is private.

## macOS

**[Download the latest Mac installer](https://github.com/aka-kolton/compliprint-agent-releases/releases/latest/download/CompliPrint-Print-Agent.pkg)**

- macOS 13 (Ventura) or newer, Apple silicon or Intel.
- Signed with Patriot Print Fulfillment LLC's Developer ID and notarized by
  Apple, so macOS opens it without a warning.
- Installs **CompliPrint Print Agent** in Applications. It runs in the menu
  bar and starts when you log in.

Every version is listed under [Releases](https://github.com/aka-kolton/compliprint-agent-releases/releases).

## Help

Setup steps are on the Help page inside CompliPrint, under **Downloads**.
